# Gallery Showcase Folder

Drop your photos here (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`).
They will automatically appear in the **Drift Wall** on the Gallery page!

Whenever you drop new photos or MP3s into `assets/audio/`, run:
```bash
npm run sync
```
Or keep the live watcher running while working:
```bash
npm run watch
```
When deployed to Vercel/GitHub Pages, the `build` script automatically syncs everything on deployment.
